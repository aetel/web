<p>Do you have a Nokia 5110 Screen but you don’t know how to use it or you know it but you want to add some extra functionalities? In that case, you may be interested in using a library that will allow you to write in different positions as you would do when using Word from the Office suite and also to do it in both Spanish and English language, so there are no excuses to write without accents or the ‘ñ’ character.</p>
